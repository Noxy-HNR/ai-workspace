🧰 Scripts

A curated set of the repo's utility scripts. Quick ones (Diagnostics, window listing, screenshot, launch/focus) run and return output immediately. Slow ones (Update Stack, Model Compare's compare/quick) run in the background and restart llama-server one or more times -- their output is tailed live below once started. Not every script in the repo is here on purpose: setup.ps1 and start.ps1/stop.ps1 prompt interactively or duplicate the Services tab's own controls, and windows-control.ps1's raw mouse/type/key actions are left to cptr, since a misclick here would send real keystrokes to whatever window happens to have focus.
